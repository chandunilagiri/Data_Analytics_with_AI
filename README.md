# 📱 Flipkart 5G Mobile Web Scraping Project

A complete web scraping and data extraction project built using Python, Requests, BeautifulSoup, Pandas, and CSV processing.

This project automatically collects information about 5G smartphones listed on Flipkart under ₹50,000 and converts unstructured web data into a structured dataset for business analytics and market research.

---

## 🚀 Project Overview

The objective of this project is to build an automated web scraping pipeline capable of:

- Extracting product information from Flipkart
- Collecting pricing details
- Capturing technical specifications
- Gathering customer ratings
- Creating a structured dataset for analysis

The final dataset contains information about 216 mobile phones.

---

## 📊 Dataset Features

The scraped dataset includes:

- Product Name
- Price
- RAM
- ROM
- Processor
- Battery Capacity
- Display Information
- Customer Rating
- Additional Specifications
